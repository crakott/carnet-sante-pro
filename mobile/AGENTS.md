# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

Note: the project was downgraded from SDK 56 to SDK 54 because Expo Go 56.0.1 has a known bug
rejecting all SDK 56 projects (https://github.com/expo/expo/issues/46846), and Expo Go for
SDK 56 is not yet available on the App Store / Play Store. SDK 54 is the latest version with a
stable Expo Go release.
